## Features

- Magnet links, `.torrent` files and torrent links: drag and drop, or paste with Ctrl+V
- Choose which files to download and where to save them
- Watch videos while they download (sequential download + your own video player)
- Pause, resume, speed limits, download queue, seeding ratio limit
- Details for every torrent: files, peers, trackers and piece map
- Light and dark themes
- Keeps downloading in the system tray, with a notification when a download finishes (Windows, and Linux desktops with a tray)
- Tells you when a new version is out

## Updating

TorrentXDesk checks for updates automatically; you can also use **Settings → Check for updates now**.
On Windows it updates itself. On Linux it opens this page so you can download the new package.
Updating keeps your torrents and settings.
